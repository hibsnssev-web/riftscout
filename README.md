# Rift Scout

A free fan guide to League of Legends champions: strengths and weaknesses, abilities and lore for every champion, and every item in the shop.

- Strengths and weaknesses are Rift Scout's own notes.
- Lore, ability and item text and their icons are loaded from Riot Games' Data Dragon, so they follow the current patch.
- Riot's text is available in English, German and Hungarian.

The site is plain HTML, CSS and JavaScript with no build step. Open `index.html` or serve the folder with any static web server.
